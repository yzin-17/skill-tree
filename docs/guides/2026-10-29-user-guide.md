> 首次创建：2026-10-29；最近更新：2026-10-31。
> 适用版本：0.1.0（构建 26），本机 macOS 原生应用与 Docker 后端。当前应用图标见[图标验收](../reviews/2026-10-31-app-icon.md)。最新操作依据：[后端地址验收](../tasks/backend-address/evidence/2026-10-30-implementation.md)、[界面精简验收](../reviews/2026-10-30-ui-labels.md)、[星图工具栏验收](../reviews/2026-10-30-skill-toolbar.md)、[图钉交互验收](../reviews/2026-10-30-task-pin.md)、[月历原生验收](../tasks/activity-calendar/evidence/2026-10-30-implementation.md)及[手动登录验收](../tasks/optional-login/evidence/2026-10-30-implementation.md)；既有行为见[首版原生验收](../archive/tasks/skill-atlas-v1/evidence/2026-10-29-native-ui.md)、[成长路径复验](../tasks/growth-paths/evidence/2026-10-30-implementation.md)及[全界面文案复验](../tasks/ui-copy-cleanup/evidence/2026-10-30-implementation.md)。安装、更新和数据位置见 [本机运行说明](2026-10-29-local-operation.md)。

## 开始使用

使用默认本机后端时，先启动 Docker Desktop，再在项目目录执行 `python3 scripts/local.py up`。打开 `~/Applications/Skill Atlas.app`，使用所连接后端的账号登录；首次使用可在登录页选择“创建账号”。账号与历史属于对应后端，停止后端会保留数据。

默认每次启动使用账号密码登录，令牌仅保存在本次运行内存。需要跨启动恢复时，可主动勾选“记住登录”；设置中可以取消。未启用时不访问钥匙串，升级后也不会自动读取旧凭据。

在设置的后端卡片点击“编辑地址”，或从登录页点击“后端地址…”，可以填写 HTTPS 服务根地址、检查连接、保存或使用默认地址。保存后立即切换，重启后保留；取消仅关闭弹窗。不同后端分别保存登录与本机记录，切回原地址可恢复；正在专注时会先确认暂停并保存。连接不可用时也能从登录页重新修改地址。

登录后进入工作台。这里显示今天的投入、成长、成功次数、今日或置顶任务、当前阶段与称号以及近期活动。可以直接新建任务、开始专注，或进入技能星图建立自己的学习路线。应用不会自动生成待办。

## 建立技能树

在“技能星图”的“更多”菜单新建技能树，填写名称、描述、主题和排序。标题下方靠左选择技能树并搜索，右上角“新建技能”用于添加当前树的根技能；打开节点右侧详情，使用“添加子技能”会预填当前技能作为父级。父子必须属于同一棵树。

图标从固定图库中选择，可搜索、预览、更换或恢复默认星标。保存后图标不会随机变化。编辑当前技能树或技能可调整内容、排序和归档状态；归档保留记录，隐藏日常入口。需要查看归档对象时，在“更多”中开启“显示已归档”。有子技能、关系、任务或历史引用的技能不能直接删除，应使用归档。

节点详情从右侧覆盖展开。可缩放、平移或使用“适合窗口”；关闭详情后保留视口。详情中的父级、子级、关系和搜索结果可以定位节点，跨树关系会切换到对应树。

## 配置前置与普通关联

在技能详情的“前置与关联”中添加关系，可以搜索另一棵树的技能。前置关系需要设置最低等级；全部条件满足才显示已解锁，自引用和循环会被拒绝。普通关联用于参考，不参与解锁判断。

前置未满足采用软锁定：界面列出缺口，仍允许专注和获得 XP。可以调整前置等级或移除关系。父子关系、前置关系和普通关联各自独立。

## 创建任务与确认结果

在工作台或“任务”中手动新建目标，填写说明和完成条件，选择一个或多个技能，并为每项技能设置非负整数奖励等级。成功时每个奖励等级对应 60 XP。可设置日期、置顶、搜索和筛选；到期不会自动失败。

工作台、任务列表和任务详情的图钉均可直接点击切换置顶状态：空心表示未置顶，实心表示已置顶。悬停可查看操作名称；保存期间及离线时按钮不可用。

任务可以关联多次专注。每条专注只选择一个主技能，时间 XP 只给该技能；成功奖励可以发给任务绑定的多个技能。

结果需要手动确认。失败时填写原因，已积累的时间和时间 XP 保留，不发成功奖励；点击重试会开启下一次尝试并保留之前的失败。成功率按未撤销的成功与失败次数计算，没有有效尝试时显示“暂无数据”。取消任务不会新增成功或失败尝试。

错误结算可在尝试历史中撤销并填写原因。撤销保留原尝试和奖励流水，按当时的奖励快照产生补偿；后来修改任务奖励不会改变旧结果的补偿金额。界面会重新计算成功率、任务状态和成就资格。已有后续尝试等不允许撤销的情况会明确提示。

## 使用专注计时

在“专注”选择主技能、可选关联任务及模式；也可从任务或技能详情进入。

| 模式 | 运行方式 |
| --- | --- |
| 正计时 | 持续累计，手动结束并保存 |
| 倒计时 | 设置分钟和秒，到目标自动结束；提前结束只保存实际有效时长 |
| 番茄钟 | 设置每轮专注、休息和轮数；自动切换，最后一轮专注结束后保存，休息不计有效时长 |

同时只运行一条专注。暂停期间不累计，继续使用原现场；结束备注随现场保存，自动结束也会保留。关闭主窗口后计时继续，可通过屏幕顶部的计时器图标操作。应用“专注”菜单也能打开页面、暂停/继续、结束保存；快捷键为 Command-Shift-F 打开页面，Command-Shift-P 暂停/继续。

系统睡眠前会自动暂停，醒来后手动继续。正常退出会保存暂停现场；异常退出后重开恢复最近持久化的现场，不擅自累计未观察到的离开时段。

设置或专注页可开启到点提醒；系统允许后会显示结束或番茄钟阶段通知。拒绝系统通知仍可正常计时和保存，结果显示在应用内。本次验收结束时提醒已关闭，需要使用时可自行开启。

## 补录、历史与经验

“手动补录”需要选择主技能，填写开始/结束时间、有效分钟/秒数及备注；有效时长必须为正数且不超过所填区间。补录明确标为“手动补录”，可获得时间 XP，但不计入阶段/称号条件要求的真实计时时长。

技能从 Lv.1 开始，每 60 XP 升 1 级。时间 XP 按同一技能累计有效秒数除以 60 后取整，零散余秒会继续累计；不会每条记录分别丢掉不足一分钟的部分。界面正在计时或等待上传时显示预估，收到服务端结果后才显示“已确认”。

历史记录可打开来源，也可更改关联任务。重新关联只改变任务汇总，不改变主技能或重复发放 XP。

## 成长路径、称号与成长日志

在“成就殿堂”配置成长阶段、分支和称号，既可以用于工作，也可以用于兴趣。成长路径以父子树显示，点击阶段或称号在右侧查看详情；可用关闭按钮或 Escape 收起详情，关闭后保留原位置。首版支持技能等级、真实专注时长、成功次数、指定任务成功四类条件；逐项显示缺口和事实来源。全部条件达标后仍需手动确认进入该阶段；进阶阶段还要求已完成前一阶段。

称号达标时保存首次解锁记录，之后可选择佩戴，同时最多佩戴一个。条件因撤销等原因回退时，当前阶段和阶段历程保留；失去资格的称号自动取消佩戴，首次解锁历史仍可查看。

“成长日志”默认显示月历：周一开周，日期格显示完成次数、专注时长及失败／重试，顶部可切换月份、返回本月和筛选技能。点击日期在右侧查看当天活动与原始记录，可用关闭按钮或 Escape 返回。任务完成只统计未撤销的成功尝试；计时和补录按专注结束日归属。

“统计”和“时间线”保留。可选择日期、技能，按日/周/月汇总，时间线还可按事件类型筛选并加载更多。图表点击后显示对应时段来源；成长流水能追到专注或任务尝试，补偿流水能继续查看原奖励。结束日期包含当天。

## 离线、登录与错误处理

首版在线管理技能、任务和成就；离线保障专注计时、结束落盘及已缓存数据查看。后端恢复后会自动重试，也可在专注或设置中主动同步。等待确认的 XP 不等于已入账 XP。

退出账号前，应用会暂停并保存专注并撤销服务端会话。网络不可用导致退出尚未完成时，先恢复连接再重试。待上传记录和缓存按账号保留；其他账号看不到也不会上传原账号记录，重新登录原账号后恢复同步。认证过期会返回登录页，原记录仍保留。

| 界面提示 | 处理方式 |
| --- | --- |
| 无法连接服务器 | 在“后端地址…”或设置的“编辑地址”中核对地址，使用“检查连接”；使用默认本机服务时确认 Docker 已运行 |
| 记录已更新，请刷新后重试 | 关闭旧编辑表单，刷新后重新编辑；不会自动覆盖另一会话的新版本 |
| 前置关系会形成循环 | 调整关系方向或改为符合用途的普通关联 |
| 补录区间必须容纳有效时长 | 修正开始/结束时间或有效时长后再保存 |
| 系统通知未允许 | 继续使用应用内小结；需要横幅时到系统设置的通知页面调整 Skill Atlas |
| 记住登录失败 | 本次仍可正常登录；下次启动使用账号密码，系统授权仅在主动记住登录时处理 |

## 导出与备份

待记录全部同步后，在“设置”选择“导出 JSON…”，通过系统保存面板选择位置。成功后显示记录数量并重新读取校验，支持“在 Finder 中显示”；取消不会生成备份，权限或网络失败会明确提示。

导出包含当前账号的技能、关系、任务、专注、尝试、奖励与补偿、活动及阶段/称号历史，不含密码或登录令牌。只导出服务端已经确认的数据，尚在计时或等待上传的本机记录不在文件中。

首版提供 JSON 导出和可读取性验证，不提供恢复导入。服务端数据库保存在独立 Docker 卷，本机现场和队列在应用支持目录；数据位置、保留方式及更新步骤见 [本机运行说明](2026-10-29-local-operation.md)。
