> 首次创建：2026-10-29；最近更新：2026-10-30。

> 创建及更新：2026-10-29；任务：M5.2–M5.5；场景：B04/B05、C01–C06、C08/C09、C11–C13。

实际实现包含尝试、关联技能快照、奖励、重试请求、撤销事实及补偿流水。使用稳定请求 ID、账号事务锁、尝试编号和任务版本拒绝冲突；原响应保留为结算快照，当前状态通过查询读取。

执行 `python3 scripts/local.py test ./internal/httpapi ./internal/task/...` 通过，使用真实隔离 PostgreSQL Schema，包含已有 I1 实际 HTTPS 进程与重启检查。定向测试位于 `attempt_test.go`、`attempt_lifecycle_test.go`。

- 失败保留 30 时间 XP，任务奖励为零；成功多技能各自发奖励，同 ID 五次并发与不同 ID 四次竞争只结算一次。
- 修改任务配置不会更改历史奖励；注入奖励写入故障后，尝试、奖励、成长和活动事件全部回滚，同 ID 可重试成功。
- 失败后重试开启编号 2，重复请求不推进编号；失败与成功保留为两条历史，成功率为 50%，不因多技能重复计数。
- 有后续尝试时禁止撤销旧结算；补偿故障不改变任务/奖励/统计。五次并发撤销只补偿一次，原奖励和撤销事实都保留；任务进入编号 3 的进行中状态。
- 撤销失败后零分母恢复为空；取消不产生新尝试；他人结算、重试、撤销和历史引用均被拒绝。

本证据覆盖后端事实，不代替原生交互、菜单栏或成就回退门禁。
