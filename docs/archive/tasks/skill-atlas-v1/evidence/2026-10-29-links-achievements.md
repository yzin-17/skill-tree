> 创建及更新：2026-10-29；任务：M6.1/M6.2、M7.1–M7.3；场景：A02–A04/A10、D01–D04/D07/D09。

C-LINK 与 C-ACHIEVEMENT 以 `server/contracts/skill-link.yaml`、`achievement.yaml` 的同源 fixture 为准。关系和条件纯检查通过；`python3 scripts/local.py test ./internal/httpapi ./internal/achievement/...` 使用真实隔离 PostgreSQL 通过。

关系验证包括跨树查询、稳定 ID 重放/冲突、重复有效边、自引用、两节点和四节点循环、普通关联反向连线、他人引用、前置缺项、阈值版本冲突、重复删除。软锁不阻止专注；目标技能因奖励升级后解锁，撤销后重新显示缺项。

成就验证覆盖跨树等级、真实专注分钟、成功次数、指定任务四类全部满足求值。手动补录获得时间 XP，但真实时长条件仍为零；实际计时来源会话可追溯。职业达标不自动转职，手动确认稳定 ID 重放不增加历史，父级循环被拒绝。

称号首次达标解锁；佩戴切换保持唯一。任务撤销或提高条件阈值后，取消失效佩戴且保留原解锁证据；重新达标不重复解锁。职业当前身份及历史保留。注入解锁活动事件写入故障后，触发它的任务奖励和尝试整体回滚，原 ID 可重试成功。跨账号配置和查询隔离通过。

当前证据为服务端及条件契约层；星图、职业/称号界面与实际安装仍由各原生任务及门禁承接。
