# 统计与导出验证

> 首次创建：2026-10-29；最近更新：2026-10-30。

> 创建及更新：2026-10-29；任务：M8.4/M8.5、M9.2/M9.3；场景：C09、D05/D06/D10、F05 的后端部分。

C-STATS 和 C-EXPORT 位于 `server/contracts/stats.yaml`、`export.yaml`。统计按账号时区与周一边界求值；窗口 XP 取实际流水，保留跨窗口余秒累计的入账事实。范围内数据提供原始来源 ID，累计汇总和账号成就历史使用明确的响应字段。

`stats_test.go` 使用真实隔离 PostgreSQL 和显式日期事实验证：周日 20 秒与周一 50 秒累计为 1 XP；补录单列；多技能尝试不重复计数；失败、重试、成功、撤销、再次成功后汇总一致；当前技能解绑不改变历史筛选；日空桶、零分母、越权及无效范围正确。共享契约检查覆盖月边界及纽约夏令时结束的 25 小时日期。

导出采用 20 个业务数据集的字段白名单，在同一可重复读快照读取本账号。`export_test.go` 覆盖多会话、失败重试、成功奖励及补偿、已移除关系、职业转职、称号解锁/佩戴、已删除技能事件与尚未结束的本地事件。导出文件写入隔离临时目录后重新读取，格式/数量/结构化引用一致，不含密码、令牌、认证会话和请求散列。另一个账号导出为空；未登录与 user_id 覆盖参数明确拒绝。

首次导出测试发现身份覆盖参数被忽略而未报错，已在统一认证入口拒绝该参数；本账号隔离始终生效。修复后 `go vet ./...` 及 `go test -race -count=1 -json ./...` 全部通过，共 24 个 Go 测试，包含实际 API 进程 HTTPS/重启 I1。输入文件 SHA-256 清单保存在 `.runtime/acceptance/backend-manifest-2026-10-29.json`，详细输出在 `.runtime/logs/backend-final-race.jsonl`。

原生保存面板、图表下钻和目标安装仍待其独立验收。本报告不把后端文件读取当作原生导出交互已通过。
