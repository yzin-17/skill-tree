## SwiftData 与生命周期协调器（M3.4/M3.7）

`swift test --package-path macos --filter 'FocusLifecycleTests|FocusPersistenceTests|FocusEngineTests|PomodoroTests'`：14 项通过。

- 使用实际临时 SQLite/SwiftData 文件保存并重开，确认同会话 UUID、账号及小数有效时长保留。
- 结束记录、四类生命周期事件与活动现场收尾在一次保存中提交；重复结束不增加记录。
- 在提交前注入保存错误，再用新存储实例重读：原活动现场仍在，结束队列和结束事件均未部分落盘；重试后成功保存。
- 账号队列隔离、其他账号不能修改记录、同 ID 不同内容被拒绝；同一设备不能同时保存两个运行中的现场。
- 模拟睡眠、正常退出和重开：暂停区间不计入，原账号恢复同会话；保存失败不确认完成、不发送结束通知，成功保存后只通知一次。

这些是本地状态/存储和生命周期事件模拟证据。系统通知观察者、菜单栏、实际睡眠/退出和跨进程恢复仍待 G1；网络上传仍待 M4.4/M8.3。
