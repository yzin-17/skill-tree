# 手动登录与可选记住登录规格

首次创建：2026-10-30  
最近更新：2026-10-31  
任务标识：optional-login  
状态：已验收，当前契约
对应任务：[登录修复任务](../archive/tasks/2026-10-30-optional-login.md)

## 目标与范围

用户连续指出启动反复要求钥匙串授权。默认采用账号密码登录，只有主动勾选“记住登录”才启用跨启动会话恢复。密码不落盘；未勾选时令牌仅保存在本次进程内存。保留 Go 自管认证、TLS、账号数据隔离、专注保存和既有记录。

本规格更新首版默认从钥匙串恢复及强制保存的行为。已有钥匙串条目不构成新的启用意愿，升级后新增偏好默认关闭，不自动读取旧条目。用户打开记住登录时仍由 macOS 管理令牌的安全保存，不写入普通配置文件。

## 会话行为

- 默认启动直接到登录页，登录、时区保存、退出及过期处理均不依赖钥匙串；登录偏好只保存是否启用记住登录，后端地址作为独立连接配置保存。
- 勾选记住登录时，成功认证后尝试保存令牌。保存拒绝或失败不撤销服务器登录，退回内存会话并关闭记住偏好，以短状态提示本次登录未保存。
- 允许自动恢复时，钥匙串读取使用禁止交互的认证上下文；无法静默读取时回到账号密码登录，不要求用户每次更新后授权。恢复界面提供“账号密码登录”出口，晚到响应不得覆盖用户的新登录。
- 退出先保存当前专注，再撤销服务器会话；成功后清除内存和记住偏好，可选凭据清理失败不阻止退出。服务器退出失败时保留当前会话，允许重试。
- 账号时区以服务器返回值更新内存；仅已启用记住登录才静默更新持久令牌快照。快照保存失败不回滚服务器已保存的时区。
- 关闭记住登录保持当前会话，之后启动需要重新输入账号密码；旧条目清理为禁止交互的尽力操作，应用不再恢复其会话。
- 账号设置展示邮箱、登录状态及账号操作；时区不作为界面配置项，内部日期计算采用服务器账号值。界面精简见[原生验收](../reviews/2026-10-30-ui-labels.md)。
- 会话、记住登录偏好及本机记录按后端来源隔离；默认后端保留原键和原目录。切换会停用旧内存会话，目标后端仅恢复其自身记住的会话，详见[后端地址规格](2026-10-30-backend-address.md)。

## 验收标准

| 标识 | 断言 |
| --- | --- |
| AC1 | 默认启动及完整手动登录生命周期不调用会话保管库，不保存密码或普通文件令牌 |
| AC2 | 只有明确选择记住登录才保存会话；保存失败仍保持在线登录并提示结果 |
| AC3 | 已启用的有效会话可恢复；读取失败、过期或服务器拒绝回到登录；取消恢复不会接受晚到会话 |
| AC4 | 时区保存、退出、401 过期及账号专注保存边界保持一致，凭据清理不阻挡已完成退出 |
| AC5 | 登录页可直接输入邮箱密码，记住登录默认未勾选；设置可关闭记住状态 |
| AC6 | 最终本机应用在保留旧钥匙串条目的情况下可直接启动到登录页，无强制系统认证；用户登录后继续月历原生验收 |

## 验证

将会话控制器移入现有可测试核心目标，以隔离偏好、会话保管库和 URLSession 测试认证生命周期。定向测试记录保管库调用次数，证明未启用路径完全跳过保管库；模拟保存失败、401、过期及迟到恢复。原生验收默认由用户在应用内输入；2026-10-30 用户明确授权 Agent 操作此前由 Agent 创建的隔离验收账号时，可使用本会话留存的原始注册凭据，保持原账号与记录。

禁止交互上下文遵循 [Apple 的 LocalAuthentication 接口](https://developer.apple.com/documentation/localauthentication/lacontext/interactionnotallowed)和[钥匙串认证上下文](https://developer.apple.com/documentation/security/ksecuseauthenticationcontext)。不读取、修改系统认证窗口或替用户授予权限。
