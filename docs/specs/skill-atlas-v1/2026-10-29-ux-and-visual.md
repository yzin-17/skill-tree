# 页面、交互与视觉规范

> 文档标识：`skill-atlas-v1-ux`；首次创建：2026-10-29；最近更新：2026-10-30。

> 归属：[产品 Spec](../2026-10-29-skill-atlas-v1.md) 的交互附件。当前任务与证据统一见 [实施计划](../../archive/tasks/2026-10-29-skill-atlas-v1.md#current)。本文描述设计，示意图不证明原生实现已经存在。
> 业务未决规则以 [Spec 问题清单](../2026-10-29-skill-atlas-v1.md#questions) 为准；配色、图标数量和动效强度属于表现建议，右侧 Drawer、手动入口和原生交互约束保留。

## 1. 交互原则

1. **手动创建是主入口**：始终能在首页、技能树、任务页面快速找到“新建”。
2. **任务和计时相互独立**：任务可有零到多次专注；自由专注也可以后续挂到任务。
3. **详情用右侧 Drawer**：点击技能节点弹出抽屉，**不把选择区移动到画布下方**；抽屉关闭后保留星图的缩放、平移与选中高亮。
4. **展示优先、编辑简单**：技能树视觉可以有游戏感，但创建子技能和关系的交互要清晰；不要求随意拖动节点。
5. **等级只根据可追溯的记录变化**：交互中显示本次 +XP、预计升级、来源和可撤销的结算结果。

## 2. 页面规划

### 2.1 工作台（默认首页）

macOS 原生三栏布局：

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Skill Atlas               搜索 / + 新建                          头像      │
├──────────────┬────────────────────────────────┬──────────────────────────┤
│ 工作台       │ 今日任务 / 手动创建              │ 当前专注                 │
│ 技能星图     │ • 完成 Go 登录接口 [开始专注]    │ Go | 25:00 [开始/暂停]  │
│ 任务         │ • 练习 SQL JOIN [开始专注]       │ 今日 82 分钟            │
│ 专注         │ 最近失败 / 待重试                │ 技能升级 / 最近称号     │
│ 成就殿堂     │ 任务成功率趋势                   │ 最近活动                │
│ 成长日志     │                                │                          │
└──────────────┴────────────────────────────────┴──────────────────────────┘
```

- 任务栏优先处理正在进行/手动置顶的任务，支持直接创建、开始专注、成功、失败、重试。
- 当前专注支持正计时/倒计时/番茄钟切换；快捷入口可独立选择技能。
- 不展示周期任务推荐或“今日自动生成待办”。

### 2.2 技能星图（主要视觉页面）

```text
┌───────────┬────────────────────────────────────────────────────────────┐
│ 树列表    │  顶部：树名称 / 新建根技能 / 搜索 / 缩放 / 居中            │
│ 前端开发  │                                                            │
│ 后端开发  │      ◉ 前端核心 Lv.12 ───── ◉ React Lv.8                  │
│ 语言学习  │          │                         ╲                       │
│           │       ◉ 性能优化 Lv.6           ◌ 并发编程 [未解锁]       │
│           │                ─ ─ ─ > 跨树关联入口                        │
│           │                                                            │
└───────────┴────────────────────────────────────────────────────────────┘
                       点击节点后从右侧覆盖抽屉
┌────────────────────────────────────────────────────────────────────────┐
│                                                    ┌──────────────────┤
│                                                    │ [图标] React     │
│             星图继续保持当前位置                   │ Lv.8 35/60 XP   │
│                                                    │ 编辑 / 开始专注  │
│                                                    │ 创建子技能       │
│                                                    │ 前置条件 [添加]  │
│                                                    │ 跨树关联 [添加]  │
│                                                    │ 任务/历史记录    │
│                                                    └──────────────────┤
└────────────────────────────────────────────────────────────────────────┘
```

**星图设计建议（游戏感但不做复杂自由画布）：**

- 深色渐变/夜空背景，主节点采用发光外环和等级铭牌，普通节点小一档。
- **经验进度环**随 XP 更新；到 60 XP 时触发短暂升级扩散动画。
- 前置依赖用较明显的方向性连线，普通关联用较淡虚线；跨树关联显示另一棵树的名称和可点击入口。
- 锁定节点用降低对比度、锁徽和“缺少：Go Lv.5”提示；完成前置时由灰转亮。
- 鼠标悬停突出相邻节点与连线；点击节点打开抽屉，不强制移动页面。
- 利用 SwiftUI 动画与 Canvas/Path 绘制连线；节点本身保留独立交互和辅助功能；尊重系统“减少动态效果”设置。
- Mac 小窗口时抽屉仍从右侧**覆盖**画布，可提供适当宽度和关闭按钮，而不是将详情压到画布下方。

### 2.3 右侧技能 Drawer

区域从上到下：

1. 标题行：图标、名称、当前技能树、关闭按钮。
2. 核心状态：Lv、当前 XP/60、总专注时长、时间 XP / 任务奖励 XP。
3. 主要操作：开始专注、创建子技能、编辑技能、图标“更换”。
4. 父子关系：父技能（可跳转），子技能列表，新增子技能。
5. 前置条件：技能搜索器，允许跨技能树选择技能与最小等级，删除条件。
6. 普通关联：添加跨树或同树的技能引用；明确标注其“不影响解锁”。
7. 关联任务和最近事件：任务/专注列表、成败统计、成长日志。

新增子技能默认继承当前技能树和父技能；新增前置必须显式选择**目标技能 + 目标等级**。使用弹窗/内嵌选择器，而非在画布上画线作为唯一途径。

### 2.4 技能创建/修改

- 字段：名称、所属技能树、父技能（可选）、图标（必选或默认）、描述。
- 图标使用**可搜索的固定图标弹窗**，按开发、知识、生活等类别组织；先提供约 16 个稳定选项，未来扩展。
- 提供图标预览、选中态和恢复默认；不得每次创建随机挑选。
- 父技能只能从同一技能树选择；跨树关联通过“前置/普通关联”单独创建。

### 2.5 任务和任务详情

- 创建时：标题、描述、完成条件（可选）、关联多个技能、每个技能的成功奖励等级、截止日期（可选）。
- 详情展示：“累计专注总时长”“专注次数”“成功/失败历史”“每项技能的奖励预览”。
- 每次专注显示：开始/结束时间、模式、有效时长、归属主技能、是否上传。
- **“继续专注”追加一条新会话**，不覆盖旧会话。
- “绑定已有专注”用于自由会话，不改变已有技能归属、不再次发 XP。
- “结算成功/失败”由用户点击并确认；失败可录入原因，之后显示“重新尝试”。

### 2.6 专注页面 + 菜单栏

- 专注页：大号计时器、模式选择、目标时间、选择主技能、可选关联任务、当前会话累计。
- 任务详情/工作台可以直达同一个计时器；同一设备首版只维持**一条正在进行的专注**，减少计时状态分叉。
- 菜单栏：剩余/已用时间、暂停、继续、结束、打开主窗口；结束时本地通知。
- 完成一条专注后弹出小结：有效分钟、获得 XP、主技能、绑定任务、可选备注；**不自动结算任务成功**。

### 2.7 成就殿堂

- 顶部个人名片：当前职业徽章、职业阶段、佩戴称号、总专注与累计成功任务。
- 中部职业路线：按固定节点排布的转职链/分叉，**可解锁/已转职/未满足条件**三种状态。
- 下部称号陈列：金属徽章、品质边框（纯视觉）、已解锁/未解锁过滤、点击查看解锁证据。
- 转职操作：先显示条件清单，再由用户点击确认，播放简短转职揭晓动画；**不自动转职、不篡改技能等级**。
- 标题和徽章有较强游戏化视觉，但规则保持简单、可追溯；首版没有复杂装备属性与加成。

### 2.8 日志和统计

- 成长日志默认显示月历，按账号时区、周一开周和六周网格查看每日有效完成与专注；日期详情在右侧覆盖展开。月份导航、技能筛选、空态及数据口径见[月历规格](../2026-10-30-activity-calendar.md)。
- 活动时间线按日期分组，支持筛选“专注/任务成功/任务失败/升级/转职/称号”。
- 图表：日周月时间柱图、技能 XP 来源分布、成功率趋势、任务失败与重试情况。
- 点选统计项可以查看对应记录；成功率不把未完成或取消任务计入分母。

## 3. 视觉语言建议

- 定位：**macOS 精致工具 × RPG 成长星图**，不是全屏游戏，也不采用赛璐璐插画风格。
- 基础界面保留 macOS 原生窗口、工具栏、菜单与快捷键习惯；技能星图与成就殿堂有更鲜明的自定义外观。
- 颜色：深色中性背景 + 蓝紫色成长高亮 + 金色转职奖励 + 柔和红色失败态；状态不只靠颜色区分。
- 动画：悬停发光、XP 环填充、解锁光路、升级短促粒子。限制同时播放的数量与持续时间，不妨碍快捷操作。
- 使用系统 SF Symbols 与少量自制徽章矢量图；无需随机图标生成服务。

## 4. 必做交互演示路径

1. 新建技能树“后端” → 新建“Go” → 在 Go 抽屉创建子技能“接口开发”。
2. 在“接口开发”抽屉添加前置：另一棵“计算机基础”树的“HTTP”达到 Lv.3。
3. 将“Go”与“数据库”建立普通跨树关联，能跳转查看。
4. 新建“完成登录接口”，同时绑定 Go + 数据库，成功奖励分别设置 +2 级和 +1 级。
5. 先后完成两次计时（25 分钟、35 分钟），任务累计显示 60 分钟和两条记录。
6. 第一次任务尝试结算失败 → 重试 → 结算成功；成功率按两次尝试显示 50%，奖励只发成功那次。
7. 点击技能节点打开右侧抽屉；关闭后星图滚动/缩放位置不变。
8. 在图标弹窗选择新图标，退出重开后保持同一图标。

上述路径分别对应 [验收场景](2026-10-29-acceptance.md) 的 A01–A07、B01、B04–B06、C02–C05；跨功能演示归 [G3](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g3)，计时生命周期归 [G1](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g1)，账号与同步归 [G2](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g2)。局部界面可依据已验证契约进行交互检查，完整功能仍需真实 API、持久化和目标 macOS 证据。
