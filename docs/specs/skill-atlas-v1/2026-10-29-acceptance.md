## C. 任务成败与成功率

| ID | 对应 AC | 操作 | 预期 |
| --- | --- | --- | --- |
| C01 | AC11 | 创建任务，不执行任何结算 | 成功率显示“暂无数据”，而不是 0% |
| C02 | AC10 | 任务已专注 30 分钟，手动标记失败 | 保留 30 时间 XP，任务奖励不发 |
| C03 | AC11 | 对失败任务点击重试，再标记成功 | 保留失败与成功两条尝试；成功率 1/2=50% |
| C04 | AC10 | 重复提交同一 success attempt ID | 不增加第二次成功次数，也不重复发任务奖励 |
| C05 | AC10 | 在任务成功前后修改奖励设置 | 历史成功奖励取当时快照，不随之后编辑回写 |
| C06 | AC05/AC11 | 取消一个任务 | 不算成功也不算失败，不影响成功率分母 |
| C07 | AC05 | 到达任务的截止日期但没有手动结算 | 显示逾期，**不**自动标记失败 |
| C08 | AC12 | 误结算成功后执行撤销 | 统计剔除该尝试且奖励被补偿撤销，日志保留原结算及撤销记录 |
| C09 | AC11/AC17 | 同一成功尝试关联两个技能，查看全局成功率 | 全局只按 attempt ID 计一次，不因为两个技能重复计数 |

| C10 | AC05 | 创建/编辑多技能任务、逐项设奖励和置顶；输入负数/小数奖励、重复或越权技能、过期版本 | 合法配置重读一致；非法输入明确拒绝且无部分写入；取消/可编辑状态按 Q07 |
| C11 | AC10 | 多技能成功结算在事务中途失败；同 ID 冲突及不同 ID 并发成功 | 尝试、各技能奖励、成长与活动事件全成或全败，不出现部分发放或重复奖励 |
| C12 | AC11 | 重放重试请求，尝试对不允许状态的任务重试 | 按 Q07 保持唯一逻辑新尝试，旧失败不覆盖；不允许状态明确拒绝且无奖励变化 |
| C13 | AC12 | 重复/并发撤销，或在有后续尝试时撤销旧结算 | 只补偿一次，奖励/有效统计集合/任务状态一起符合 Q07；不删除原始历史 |

## E. 端到端最小闭环

### E00｜早期真实后端路径（I1）

对应 AC02、AC05、AC07–AC09、AC18。在隔离测试库中，通过实际 HTTP 认证入口创建树、技能和任务，向同一技能上传 20 秒和 50 秒会话，再查询进度为 1 时间 XP。相同 ID 重放不增加记录/XP，冲突内容和他人资源引用被拒绝；重启服务后查询仍一致。输入可受控，Go 领域计算和 PostgreSQL 持久化必须真实连接。本场景不证明原生计时、外部身份服务或分发可用。

### E01｜完整原生用户路径（G3）

对应 AC01–AC17，逐项责任与本地检查见 [实施计划](../../archive/tasks/2026-10-29-skill-atlas-v1.md#coverage)。复用同基线 [G1](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g1)/[G2](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g2) 的有效证据；这条流程不替代所有边界场景。

1. 用户登录后，在 Mac 上新建“开发”技能树及 Go、数据库技能。
2. 创建手动任务“完成登录接口”，设置 Go +2 级、数据库 +1 级奖励。
3. 任务执行两次专注（25 分钟、35 分钟），分别显示两条记录。
4. 第一次尝试标记失败，填写原因；失败不清除专注经验。
5. 重试后标记成功；Go 收到 +120 XP、数据库收到 +60 XP，成功率为 50%。
6. 进入技能星图，点击节点打开右侧 Drawer，查看准确的 XP 来源与任务历史。
7. 满足职业条件后由用户手动确认转职，在成就殿堂展示徽章和可佩戴称号。
8. 关闭并重新启动 App，确认数据来自服务端且与本地记录一致。

既有八步路径保留；同一集成基线还需覆盖工作台手动入口、跨树编辑/跳转、图标重开保留、统计下钻及 F05 导出。各断言引用对应责任叶的实际结果，缺少核心实现时返回该叶修复。

验收以**实际功能与可复现结果**为准，不以视觉 Demo 或静态截图视为实现完成。

## G. 证据记录约定

每次实际验收记录任务/AC/场景 ID、代码与配置版本、输入和环境、操作/命令、关键查询值、通过/失败/未执行结果及未覆盖范围。失败及修正保留在同一报告或实施记录中；不把临时截图或已失效路径作为唯一证据。运行时结果由责任叶/[G1](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g1)–[G4](../../archive/tasks/skill-atlas-v1/2026-10-29-gates.md#g4) 原位登记到 Task。
