## 目标与范围

在成长日志增加默认打开的月历，让用户按天查看历史任务完成与专注投入。保留统计和时间线，沿用 SwiftUI、深色系统字体、蓝色数据与现有账号时区。本文承接[成长路径与文案约束](2026-10-30-growth-paths.md)，不增加常驻教程或说明段落。

范围为只读历史展示；使用既有统计、活动和原始记录接口，不新增计划排期、自动结算、账号策略或后端数据结构。

## 月历与状态

默认显示账号时区的当前月，周一为首列，固定六周、七列，邻月日期减弱显示且不可选择。支持前月、后月、本月及技能筛选；标题与查询范围始终一致。今天以日期标记突出，选中日期使用独立边框，不把日期标记当作有完成记录。

月汇总显示任务完成次数、有效专注时长和有记录天数。日期格展示有效成功次数、专注时长，失败及重试使用文字状态；零值不伪造成成就，未来或无记录日期保持空格内容。数据加载时保留月历骨架，数值未返回时显示占位而非零；错误有局部重试入口。快速切月、筛选或切换账号时区不会让旧响应覆盖当前月份。

## 数据口径

月度查询复用 `/v1/stats/summary`，以账号时区的月首零点为包含起点、下月首零点为不包含终点，`bucket=day`。日格按日期关联服务端分桶，不按数组位置或固定秒数推算。专注按结束日归属，计时和补录都计入有效专注。任务完成数取未撤销的成功尝试，失败、重试独立显示；撤销导致的负 XP 原样保留。多技能任务在全部技能月汇总中只计一次，不累加技能小计。

有记录天数为日分桶存在专注、尝试、重试或成长流水来源的天数，不声称是连续打卡天数。活动日志是发生时的历史，统计是当前有效结果；日详情保留两者的真实标签，并可打开原始记录查看撤销状态。

## 日期详情

点击当月日期，在右侧覆盖面板查看当天汇总与活动记录，月历不向下插入内容。面板可独立滚动，包含日期、关闭按钮、有效结果和按时间排列的原有活动列表；支持原始记录钻取、分页和错误重试。关闭或 Escape 返回月历，保持月份与滚动位置。切月或技能筛选关闭已选详情；窄窗口仍可关闭并查看记录。

## 验收标准

| 标识 | 可观察断言 |
| --- | --- |
| AC1 | 成长日志默认月历，前后月、本月、技能筛选正确；统计与时间线仍可切换 |
| AC2 | 六周七列按账号时区和周一排列，闰年、跨年、夏令时及月首边界正确 |
| AC3 | 任务完成、专注、失败、重试及净 XP 与既有统计口径一致；零、未加载、错误可区分 |
| AC4 | 日期在右侧展示当天记录，原始记录与分页可用；关闭、Escape、筛选清除不展开页面 |
| AC5 | 日期按钮可由键盘及可访问性激活，名称包括日期与有效结果；常规和窄窗口不遮挡关键控制 |
| AC6 | Release 安装后用原账号、本机后端完成原生复验，保留用户记录；新数据算法有定向测试 |

## 验证与默认决定

默认周一开周和六周网格，避免切月时整页跳动。截图检查使用现有原生 AX 工具、常规及 840 × 560 点窗口；网页检查器不能验证 SwiftUI。样式沿用已验收界面，本次组件扩展不重新抽取方向。测试覆盖时区、月份、缺失／零分桶与负值；真实验收使用已有记录，不为演示写入账号数据。无阻塞问题。
