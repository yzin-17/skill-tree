# 专注阶段确认与菜单栏计时

首次创建：2026-11-10；最近更新：2026-11-10

## 行为与边界

- AC1：番茄钟每轮专注结束、休息结束、最后一轮完成时均有默认开启的声音提醒；声音开关独立于系统通知授权，保留用户选择。
- AC2：系统横幅沿用既有通知开关；未设置过开关时默认开启，在首次开始或继续限时专注时申请授权。拒绝授权、关闭横幅及投递失败须显示可理解的状态，计时保存继续生效。系统声音与应用声音不得重复播放。
- AC3：迟到的观察停在首个阶段结束点，只提醒该阶段结束；完成提醒以会话标识去重，确认开始下一阶段时不重复响铃。
- AC4：菜单栏使用等宽数字，同一时间格式内所有秒数的展示宽度一致；跨小时允许时间格式增长，停止计时后恢复仅图标。

- AC5：每轮专注结束后弹窗询问是否开始休息，休息结束后询问是否开始下一轮专注；休息为零时询问是否直接开始下一轮。只有用户确认才开始下一阶段，等待期间暂停计时。
- AC6：弹窗提供开始下一阶段、稍后继续、结束并保存。稍后继续保留暂停现场；专注页和菜单栏可确认继续。待确认状态持久化，重开可恢复，账号或会话变化后旧弹窗不得操作新会话。
- AC7：最终一轮专注完成后保存；休息和等待不计入有效专注。通知权限或开关不影响阶段确认弹窗。

同步接口、休息计分及睡眠暂停规则保持兼容，不修改真实用户数据；源码通过 Git 提交并推送，不发布或替换已安装应用。

## 验收

提醒采用可注入的通知和声音适配器，使用真实计时协调器验证各阶段、等待确认、暂停继续、恢复、保存失败、关闭开关、拒绝授权和投递失败；字体用 AppKit 实测不同数字组合宽度。原生弹窗验证标题、按钮、响应、后台唤起及过期响应隔离，应用构建验证集成。系统是否实际显示横幅、扬声器是否可听见依赖 macOS 通知设置和输出设备，单独记录实际验收边界。
