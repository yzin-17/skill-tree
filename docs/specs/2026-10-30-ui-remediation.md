## 背景与目标

依据 [build 10 原生界面评审](../reviews/2026-10-30-ui-review.md)，修复 UI-01 至 UI-08。目标是让筛选、选择和操作保持一致，缩短任务操作路径，以合适的密度展示真实投入、成长差距和结果。保留 SwiftUI、AppKit、Swift Charts 与现有深色、系统字体及蓝色成长数据的视觉基础。

成就树、成长阶段术语、右侧详情及说明文案清理以 [成长路径与成就交互规格](2026-10-30-growth-paths.md)为准；其余行为继续适用。

## 范围与约束

本轮修改 macOS 展示与展示模型、必要的定向测试、打包版本和验收脚本。现有源码已保存在 `.runtime/ui-remediation-2026-10-30/baseline`，当前目录没有 Git 元数据。不得覆盖无关文件或用户记录。

继续使用 Go 自管账号、本机 Docker 后端、原生安装包。数据模型、XP 结算、软锁规则、累计秒数取整、补录奖励、撤销补偿与历史保留均沿用 v1。无需数据库迁移。保持技能详情在右侧覆盖画布、保留视口；任务结果由用户明确确认。

## 界面行为

### 选择与任务操作

搜索或筛选后，选中对象若已不属于当前集合，立即清除详情选择。外部跳转到任务时，先调整筛选以确保目标可见，再选择。区分账号无任务、筛选无结果、尚未选择三种状态。

任务标题、完成条件与操作区位于详情前部。“继续专注”为主要操作，“确认成功”“记录失败”紧邻并保持次级强调；低频取消放入更多菜单。确认、失败、重试及撤销沿用原有确认弹窗和持久化命令。统计、奖励与可折叠历史放在操作之后。

### 密度与成长路径

工作台以任务为主区，宽窗口将当前专注及成长目标作为辅助区；窄窗口将任务放在上方，专注与成长摘要并排置于下方，确保首屏能看到下一阶段和具体差距。指标与最近活动紧凑展示。活动在无日期分组处使用账号时区的“今天／昨天／短日期”。

专注配置采用固定的标签对齐和合理字段宽度；同步、提醒形成紧凑状态区，保留失败和重试信息。历史条目保留名称、时长、来源、备注和关联入口，减少重复留白。

成就概览压缩，职业与称号直接呈现条件达成数及未满足的具体差距。条件依据服务端 evaluation，不推导或授予资格。软锁节点的可视标签与可访问性标签均说明“可练习”，悬停或选中呈现前置差距。

### 统计与可访问性

无数据、单个有效日期及多个日期分别采用空态、紧凑摘要和趋势图。保留选定区间与真实零值，日期范围变化必须由用户操作；提供近 7 天快捷范围。时间图显示分钟单位；成功率显示百分比及成功数／有效尝试数，单点必须显示日期。

技能投入采用名称、对比条形、时长和 XP 同行的列表。保留稳定 ID 作为身份，但可访问性名称使用技能名及所属技能树，数值说明时间 XP、任务净奖励及总 XP，不读出 UUID。

### 成果时间线与详情

默认按专注会话呈现成果，优先采用 `focus.recorded` 中服务端确认的 `effective_seconds`、`awarded_xp` 与 `task_id`。同一会话的过程事件只按 `entityType == focus_session` 与 `entityId` 归组，不能按时间近似匹配；不重复累加 XP。分页加载按事件 ID 去重，分页未完整时只表述已加载的过程，不冒充完整历史。

列表直接显示技能、有效时长、已确认 XP 和关联任务；过程可展开，全部事件筛选仍可访问原始记录。没有确认记录的进行中／历史片段如实展示，不虚构时长或奖励。详情在同一容器内导航来源，提供返回路径；技术标识放在有标签、可复制的辅助详情中。

## 验证策略

展示模型对分组、分页片段、XP 去重、日期边界及统计表现选择做定向测试；纯间距改动通过构建与原生截图验证。先在任务状态与操作修复后执行一次原生真实数据路径，随后完成其余页面。最终构建 Release、递增构建号、保留旧包并安装，核对版本和运行进程。

原生验收使用实际账号与原有 8 条专注、70 XP 基线，覆盖约 1240 × 885、1280 × 661、840 × 560 点窗口，记录实际可达尺寸。验证筛选、弹窗取消、导航、范围切换、来源追溯和可访问性。无需提交奖励或更改权限来验证展示。VoiceOver 检查仅针对改变的技能投入条目；工具或权限阻塞必须保留为未验收。

网页检查器不适用于 Swift；已确认 `lint.mjs` 不扫描 Swift，不以网页检查结果代替原生验收。按 taste-skill 最多进行三轮截图批评与定向修正，保留前后对比。

## 风险与决策

默认清除集合外选择，避免旧详情含义不清。成果聚合严格依赖实体身份；服务端确认记录是时长与奖励的权威。宽窄布局用同一套真实内容，不为画面填造记录。重装前确认没有正在计时的会话；不触碰系统认证窗口。

未决业务问题：无。实施和本机安装已由用户授权；原生验收可达性以当前环境检查为准，缺失能力不豁免 AC9。
