## 目标与边界

将当前 Skill Atlas 源码纳入 GitHub，通过 GitHub Actions 从干净检出构建 macOS 安装包，并将 CI 产物发布到同一提交对应的 Release。默认目标为账号 `yzin-17` 下的私有仓库 `skill-tree`。用户已授权本轮所需的建库、源码提交、推送、标签和 Release 发布；现有工作区与应用数据必须保留。

本轮交付客户端的通用 `.app` ZIP、可拖入安装的 DMG、构建信息及 SHA-256 校验清单。后端继续使用现有 Docker 运行方式；本轮不另行发布容器镜像，也不申请 Apple 开发者身份或公证。

2026-10-31 实施前核验：客户端版本为 `0.1.0`、构建 `26`，已有白底珠光星形图标。当时目录没有 Git 元数据或远端，CLI 未登录，已连接账号为 `yzin-17`。现已创建同账号的私有仓库并发布 `v0.1.0`；实际提交、运行及下载证据由对应已完成任务保留。

原构建脚本使用 `.runtime/client-config.json` 和 `.runtime/tls/cert.der`，不能直接用于干净检出。新增明确选择的发布公共资源目录，包含 HTTPS 根地址、证书摘要和 DER 公共证书；初始值对应现有本机 Docker 后端。私钥、数据库凭据、令牌、业务数据、工具下载和运行日志留在本机。自定义后端继续沿用既有设置与系统证书信任规则。

## 构建与发布行为

1. 本机构建的默认资源路径与安装行为保持兼容；CI 显式选择公共发布资源和独立输出目录。
2. macOS 构建同时包含 `arm64` 与 `x86_64`，最低系统目标维持 macOS 14。CI 运行 Swift 核心测试、构建、架构和签名检查；Linux 作业使用临时 PostgreSQL 执行现有 Go 测试。
3. Pull Request 和手动触发执行校验与打包；推送 `v*` 标签时，在全部检查通过后发布。首个版本为 `v0.1.0`，标签版本必须与 `macos/version.json` 一致。
4. 安装包包含当前应用图标、可执行文件和公共连接配置。打包前校验配置、公共证书、架构、签名及禁止携带的私有文件；ZIP 解包后复核签名，DMG 验证可挂载并包含应用与 Applications 快捷方式。
5. Release 先建为草稿，上传并核对完整资产后发布。已正式发布的同名版本不得静默覆盖。Release 说明使用中文，说明系统要求、架构、安装方式、后端配置、临时签名与未公证状态，并关联源码提交和 Actions 运行。
6. 发布权限限制在最终发布作业的 `contents: write`；构建作业只读源码。工作流使用固定版本的官方 Actions，设置作业超时和产物留存。
7. 若构建与测试通过后发布失败，可在手动运行中提供同仓库的 `source_run_id` 接续发布。接续前必须核对原工作流路径、标签和源码提交、原测试及打包作业成功、产物名称与有效期；仅下载该次已验证产物，沿用原构建提交和运行来源。草稿通过含草稿的 Release 列表查询，仍需满足原提交和原运行归属校验；不移动原标签，也不覆盖正式版本。

## 验证与证据层级

本地验证包括打包工具的成功路径与拒绝错误输入、工作流静态校验、干净源码副本的通用 Release 构建和安装包检查。远端门禁必须实际运行 GitHub Actions，记录提交、运行编号、作业及产物；随后从 Release 下载资产并核对校验和、应用版本、架构和签名。本机证据不能替代远端构建；交叉编译不等于 Intel 实机运行验收。

## 验收标准

- AC1：干净检出可用显式公共资源完成双架构 macOS 构建，原本机默认构建入口保持兼容。
- AC2：打包生成 ZIP、DMG、构建信息和校验清单，解包或挂载后的应用有效，私钥与运行数据未进入源码或分发包。
- AC3：GitHub Actions 的实际测试、构建、打包和产物上传全部成功。
- AC4：对应标签的正式 Release 包含同一 CI 运行的完整资产，下载校验与应用检查通过，正式发布版本不会被静默覆盖。
- AC5：文档、当前任务、Git 提交、版本标签和发布证据一致，保留既有工作区与本机业务数据。

## 风险、默认值与未决事项

- 发布包沿用 `ad hoc` 签名，首次打开可能受到 Gatekeeper 限制；正式 Apple 签名与公证需要另行配置开发者身份。
- 默认公共证书只用于当前本机后端的证书固定，不包含签名私钥；更换本地服务证书后需同步更新发布公共配置。其他有效 HTTPS 后端通过应用现有地址编辑入口配置。
- 后续发布仍需有效的仓库与工作流权限；本轮登录、权限核对和正式发布均已完成。
- 其他阻塞设计问题：无。
